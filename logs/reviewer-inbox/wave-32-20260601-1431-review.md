## Findings

### LOW-001: Before/after rerun does not consume the exported patch artifact
- Severity: Low
- File: `tests/policy/patch.test.ts`
- Evidence: The before/after fixture test compiles an agent policy directly with `compileAgentPolicy(environment, ...)`, then runs `agent.run({ mission, adapter, policy })`. It does not generate a `PolicyPatch` with `generatePolicyPatch(...)` and use that exported patch as the input to the after run.
- Why it matters: The Wave 32 verification asks for a before/after fixture rerun, and the wave goal is to export a policy patch that improves agent behavior. The current test does prove the existing contract policy path improves behavior, and the separate export tests prove the patch is schema-valid and violation-linked, but the two facts are not connected by one executable path.
- Required fix: Either add a focused assertion/test that derives the after-run policy behavior from the generated patch artifact, or explicitly document/log that Wave 32 only exports the patch and that executable patch application is intentionally out of scope for this wave.
