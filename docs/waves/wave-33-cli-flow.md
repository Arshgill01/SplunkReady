# Wave 33 - CLI Flow

## Goal

Create a simple repeatable CLI/demo flow.

## Scope

- Compile command.
- Evaluate command.
- Receipt command.
- Rerun command.

## Files Owned

- CLI files.
- CLI tests.
- command docs.

## Acceptance Criteria

- Fixture mode runs end-to-end from CLI.
- Commands produce artifacts in predictable paths.
- Errors are actionable.

## Verification

- CLI fixture smoke command.
- artifact existence checks.

## Reviewer Checklist

- Can this drive demo without UI?
- Are outputs stable?

## Stop Conditions

- CLI requires live Splunk for fixture demo.
