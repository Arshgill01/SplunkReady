# Wave 37 - UI Receipt and Rerun Views

## Goal

Show before/after readiness receipts.

## Scope

- Failed receipt.
- Policy patch.
- Rerun receipt.
- Score comparison.

## Files Owned

- UI receipt files.
- tests.

## Acceptance Criteria

- Receipt is exportable.
- Before/after contrast is immediate.
- Critical issues and fixes are paired.

## Verification

- UI fixture tests.
- screenshot check.

## Reviewer Checklist

- Does this feel enterprise-real?
- Is the receipt the artifact, not the UI chrome?

## Stop Conditions

- Rerun pass looks scripted or magical.
