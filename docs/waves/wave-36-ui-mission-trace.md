# Wave 36 - UI Mission and Trace Views

## Goal

Show mission execution and MCP trace.

## Scope

- Mission list.
- Tool-call timeline.
- Query details.
- Violations inline.

## Files Owned

- UI mission/trace files.
- tests.

## Acceptance Criteria

- Failing trace makes bad tool use obvious.
- Passing trace shows corrected path.
- User can inspect tool inputs and evidence summaries.

## Verification

- UI fixture tests.
- screenshot check.

## Reviewer Checklist

- Is trace readable in a 3-minute demo?
- Are violations grounded in trace events?

## Stop Conditions

- Trace is hidden behind a vague score.
