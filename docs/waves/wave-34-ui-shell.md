# Wave 34 - UI Shell

## Goal

Build the application shell without generic dashboard slop.

## Scope

- Layout.
- Navigation.
- Product header.
- Mode indicator.
- Artifact loading.

## Files Owned

- UI shell files.
- UI tests.

## Acceptance Criteria

- First screen shows product, mode, current agent verdict.
- UI emphasizes receipt/provenance, not marketing.
- No nested cards or vague AI dashboard patterns.

## Verification

- UI test.
- screenshot check once browser available.

## Reviewer Checklist

- Does it look like an operational tool?
- Is text clear and restrained?

## Stop Conditions

- UI becomes a landing page.
